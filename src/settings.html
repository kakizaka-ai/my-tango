設定

データ（バックアップと取り込み）

語は、このブラウザの中に保存されています。ときどき、バックアップを保存してください。端末を変えるときは、読み込みで移せます。

AI を使わずに、語を作る方法（無料の ChatGPT・Claude・Gemini など）
① 下のボタンで、AI に頼む文章を、コピーする。② 無料の AI のチャットに貼り付け、その下に、分からなかった語を、1行に1語、書いて送る。③ 返ってきた JSON を、コピーして、下の欄に貼り、「貼り付けを取り込む」を押す。

形式は、docs/data-format.md にあります。word だけでも取り込めます（意味などは、空のままです）。

AI で自動作成

語を入れると、意味・発音記号・例文などを、AI が作ります。キーは、このブラウザの中だけに保存されます。Google Gemini と Groq には、無料の枠があります。OpenAI は、使った分だけ、料金がかかります。

無料のキーの、作りかた

Google Gemini：https://aistudio.google.com を開く → Google アカウントで入る →「Get API key」→「Create API key」→ 出てきたキーを、コピーして、上の「API キー」に貼る。
Groq：https://console.groq.com を開く →「API Keys」→「Create API Key」。

PC とスマホの同期（Supabase）

同じ設定を、PC とスマホの両方に入れると、同じ単語帳になります。設定のしかたは、README.md を見てください。
