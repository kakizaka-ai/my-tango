# TOEIC 単語帳 データ仕様（3,141語）

この文書は、既存の単語帳（Claude が作成）と同じ形式のデータを、別のツールで作るための仕様です。
実データは `wordbank_full.json`、形式の見本は `wordbank_sample.json` にあります。

## 1. 概要

- 総語数：3,141（重複なし。大文字小文字は区別しない）
- 2つの単語帳（`set`）に分かれる
  - `bold`（太字）：1,759語。市販教材の索引で太字だった「見出し語」
  - `thin`（細字）：1,382語。索引で細字だった「関連語・派生語」
- 全語に、意味・発音記号・例文（と日本語訳）・ジャンルが付く
- 用途：クイズ形式の学習（「わかる／わからない」の自己申告、または4択）

## 2. ファイル形式

`wordbank_full.json`：UTF-8 の JSON。**オブジェクトの配列**で、1語が1要素（1行）。
`word` の昇順（大文字小文字を無視）で並ぶ。

```json
{"word": "acceptable", "pos": "形", "meaning_ja": "受け入れられる、許容できる", "ipa": "ækˈsɛptəbəl", "genre": "state", "set": "thin", "example": "an *acceptable* price", "example_ja": "受け入れられる価格", "headword": "accept", "derived": []}
{"word": "accept", "pos": "動", "meaning_ja": "受け入れる、受け取る", "ipa": "ækˈsɛpt", "genre": "action", "set": "bold", "example": "*accept* an offer", "example_ja": "申し出を受け入れる", "headword": null, "derived": ["acceptable", "acceptance"]}
```

## 3. フィールド定義

| フィールド | 型 | 内容 |
|---|---|---|
| `word` | 文字列 | 見出しの語・熟語。原綴りのまま（`(clothes) dryer`、`All sales are final.`、`turn X into Y` のように、記号や括弧も含む） |
| `pos` | 文字列 | 品詞。`名`・`動`・`形`・`副`・`前`・`接`・`熟語` のいずれか |
| `meaning_ja` | 文字列 | 日本語の意味。複数ある場合は「、」で区切る |
| `ipa` | 文字列 | 米音の発音記号。**前後のスラッシュは付けない**（表示時に `/…/` で囲む）。強勢は `ˈ`（第1）と `ˌ`（第2） |
| `genre` | 文字列 | ジャンルの id（第5節の15種のいずれか） |
| `set` | 文字列 | `bold` か `thin` |
| `example` | 文字列 | 例文（短いフレーズ）。対象の語を `*` で囲む（第6節） |
| `example_ja` | 文字列 | 例文の日本語訳 |
| `headword` | 文字列 or null | `thin` の語に対応する、`bold` の見出し語。対応がなければ null（`bold` の語は常に null） |
| `derived` | 文字列の配列 | `bold` の語に対応する、`thin` の語の一覧。なければ空配列（`thin` の語は常に空） |

品詞の件数：名 1,404、形 607、動 527、熟語 404、副 173、前 15、接 11。

`headword`（thin 側）と `derived`（bold 側）は、同じ対応関係を逆から表したものです。
`headword` が付く thin 語は 1,144 語、`derived` を持つ bold 語は 778 語です。

## 4. 細字・太字の意味

- `bold`：その語自体が学習の中心。答えの欄に、関連する細字の語を「派生語：…」として最大6語まで出す
- `thin`：見出し語の派生・関連語（`acceptable` ← `accept` など）。答えの欄に「見出し語：…」を出す
- どちらにも対応がない語（`able` など）は、関連表示なし

## 5. ジャンル（15種）

1語につき1つ。内容が最も近いものを選ぶ。

| id | ラベル | 件数 |
|---|---|---|
| `hr` | 人事・雇用 | 99 |
| `law` | 契約・法務・規則 | 92 |
| `fin` | 財務・お金 | 119 |
| `sales` | 販売・広告・顧客 | 126 |
| `mfg` | 製造・物流・在庫 | 121 |
| `office` | 会議・事務・連絡 | 151 |
| `travel` | 旅行・交通・宿泊・飲食 | 114 |
| `build` | 建物・不動産・設備 | 179 |
| `health` | 医療・健康・安全 | 64 |
| `edu` | 教育・研究 | 85 |
| `env` | 環境・自然・エネルギー | 89 |
| `state` | 状態・性質 | 493 |
| `action` | 動作・変化 | 396 |
| `gen` | 副詞・つなぎ・熟語 | 377 |
| `other` | その他 | 636 |

割り当ての規則：
1. 内容が上の分野（`hr`〜`env`）に当てはまる語は、その分野にする。
2. 当てはまらない語は、品詞で決める。形容詞→`state`、動詞→`action`、副詞・前置詞・接続詞・熟語→`gen`、名詞→`other`。

## 6. 例文（`example`）の規則

- 3〜5語ほどの短いフレーズ。TOEIC で出る、仕事・旅行・日常の場面に合わせる
- 対象の語（活用や複数形になった形を含む）を、**1か所だけ** `*…*` で囲む。例：`*accept* an offer`、`the merits of the plan` なら `the *merits* of the plan`
- 熟語は、熟語全体を囲む。例：`*a number of* customers`
- 例外は2語だけ。語が2か所に分かれる熟語で、2か所を囲む
  - `turn X into Y` → `*turn* a garage *into* an office`
  - `not only X but (also) Y` → `*not only* cheap *but also* fast`
- 日本語訳は、短く自然な訳にする
- 例文と訳は、既存の教材の本文を写さず、**オリジナルで作る**

## 7. 発音記号（`ipa`）の規則

- 米音。CMU Pronouncing Dictionary の音素を、IPA に変換して作る（強勢の位置を `ˈ` `ˌ` で示す）
- 熟語は、単語ごとの記号を空白でつなぐ
- 辞書にない語、略語、複合語（`AI`、`RSVP`、`well-known`、`coauthor` など）は、手作業で補う
- 空欄は不可（全語に付いている）

## 8. データの検査項目

新しいデータを作ったら、次を確かめる。

1. `word` の重複がない（大文字小文字を区別しない）
2. 全語に、`pos`、`meaning_ja`、`ipa`、`genre`、`set`、`example`、`example_ja` が入っている
3. `pos`、`genre`、`set` の値が、許可された値の中にある
4. `example` に、`*…*` の囲みが1組ある（2組になるのは、第6節の例外2語だけ）
5. `headword` が入っている語の値は、`bold` の語として存在する
6. `derived` の各要素は、`thin` の語として存在し、その語の `headword` が元の語と一致する

## 9. 学習アプリの動作（参考）

### 待ち画面（ウェブページ。保存は iPhone の localStorage）
- 画面に単語を1つ出し、「わからない」「わかる」の2つのボタンで答える（自己申告）
- ボタンを押し続けると、答え（意味・例文・日本語訳・見出し語や派生語）が出る。離すとそのボタンが押されたことになる。ボタンの外で離すと取り消し（答えは残る）
- 「わかる」を、同じ語に**3回連続**で選ぶと「習得済み」になり、すべて習得するまで出ない
- 「わからない」は復習リストに入る。**次の回から**、3〜4問に1問のペースで出る。同じ回には出さない
- 必要な「わかる」の数（解除条件）は、30（最低）、50、100、200 から選ぶ。標準は 30
- 単語帳（細字・太字・両方）と、ジャンルを絞って出題できる。選んだ範囲の全語が習得済みになったら止まる
- 習得済みの語は、一覧から1語ずつ、またはまとめて、手動で戻せる

### 学習ログ（ウェブページ）
- 10問の4択クイズ。間違いの選択肢は、同じ品詞の語から選び、選んだ単語帳の語だけを使う
- 間違えた語は次回すぐに、正解した語は 1日・3日・7日・14日と間隔をあけて出る

### 保存される状態（待ち画面、localStorage のキー `sns-wait-v2`）
```json
{
  "need": 30, "wait": 0, "speak": 1,
  "set": "t",
  "genres": [],
  "prog": { "word": { "s": 2, "d": 0 } },
  "review": { "word": { "m": 1, "s": 0, "last": 1790000000000 } },
  "cycles": 0
}
```
- `set` は `"t"`（細字）、`"b"`（太字）、`"both"`（両方）。JSON データの `set` は `thin` / `bold` と書く（別の表記）
- `prog[word].s`：連続で「わかる」にした回数。`d`：1 なら習得済み
- `review[word].m`：「わからない」にした回数。`last`：最後に出題した回の開始時刻

## 10. 注意

- 語は、市販教材の索引から選んだものです。意味・例文・日本語訳・ジャンルは、教材の本文を転載せず、独自に書いた内容です。**新しく作る場合も、教材の本文を写さないでください。**
- 意味と例文は、1語ずつ人の目で確かめてはいません。不自然な語がある可能性があります。
