# Codex への引き継ぎ

このファイルは、マイ単語帳の開発を、Codex に引き継ぐための説明です。最初に、これと `README.md`、`AGENTS.md`、`docs/data-format.md` を、読んでください。

## 1. これは何か
- TOEIC 用の、個人の単語帳（日本語の画面）。分からなかった英単語を入れると、AI が、意味・発音記号・例文・派生語を付けて、単語帳にする。
- **ブラウザだけで動く静的ページ**（`index.html` 1枚）。サーバーはない。
- 公開先：GitHub Pages　https://tomokaki14-dotcom.github.io/my-tango/
- リポジトリ：https://github.com/tomokaki14-dotcom/my-tango（ブランチは `main`。`main` に push すると、約1分で公開ページが更新される）
- もとは claude.ai の「アーティファクト」だった。Claude は解約済み（または、解約予定）。以後は、Codex が、直す。
- 使う人は、1人（持ち主）。PC（Windows）とスマホ（iPhone）で使う。

## 2. 作りの要点
- **直す場所は `src/app.html`**（画面・CSS・JavaScript が、すべて1ファイル）。`index.html` は、生成物なので、直接は直さない。
- `python build.py` が、`src/app.html` ＋ `src/shim.js` ＋ `src/settings.html` ＋ `supabase/setup.sql` から、`index.html` を作る。`build.py` の `PATCHES` は、置き換えの数が合わないと、失敗する（わざと）。
- アプリは、claude.ai 用に書かれている。`window.claude.use(name)` で、次の3つの部品を受け取る。
  - `db`：`collection('words').onSnapshot(cb, errCb)`、`doc('words/<id>').set(obj)`、`.delete()`
  - `sample`：`sample.json(prompt, {signal})`。失敗は、`{code, message}` で reject
  - `downloads`：`save({filename, data})`
- `src/shim.js` が、この3つを、ふつうの Web の仕組みで、作る。
  - `db`：`localStorage`。同期を設定すると、Supabase にも書く（20秒ごと、画面に戻ったとき、回線が戻ったときに、取り込む。送れなかった変更は、あとで再送）
  - `sample`：OpenAI の Chat Completions（キーは、設定の画面で、ブラウザの中にだけ保存）
  - `downloads`：Blob と `<a download>`
- Supabase との通信は、`supabase/setup.sql` の3つの関数（`mytango_list` `mytango_put` `mytango_delete`）だけ。表には、直接さわらない。同期コード（16文字以上）が、パスワードの役目。
- 語のデータの形は、`docs/data-format.md`。**この形を、こわさない。** 古いバックアップが、読めなくなる。

## 5. 守ること
- 語のデータの形を、こわさない（`docs/data-format.md`）。項目を足すのは、良い。
- API キー、Supabase のキー、同期コード、パスワードを、ファイルに書かない。コミットしない。会話にも、貼らせない。
- `data/` は、持ち主の、本物の語のバックアップ。**消さない。書き換えない。GitHub に載せない**（`.gitignore` で、除いてある）。
- アプリ本体（`src/app.html`）では、`alert` `confirm` `prompt` を、使わない。
- 画面の文は、日本語で、短く、やさしい言い方にする。持ち主は、専門用語に、詳しくない。操作の説明は、具体的に（どのボタンを、どの順に、押すか）。
- Supabase の**秘密のキー**（`service_role`、`sb_secret_…`）は、アプリに、絶対に入れない。

## 6. 守る見た目と動き（これまでに、持ち主が決めたこと）
**全体**
- 画面は4つ：**追加**、**単語帳**、**復習**、**間違い**。右上に「⚙ 設定」。
- パソコン（幅900px以上）：全部の画面で、幅は1040px、見出し・タブの位置は、同じ（画面を切り替えても、ずれない。`scrollbar-gutter: stable`、同じ余白）。
- **追加と復習は、スクロールなしで、窓に収まる**（高さ520px以上のとき。実際の持ち主の画面は、高さ約600px）。単語帳と間違いは、スクロールして良い。
- 語のカードは、画面を問わず、同じ大きさ（「追加」の右の、1枚の幅が、基準）。単語帳と間違いは、2列。
- スマホ（幅360〜430px）：1列。横にはみ出さない。復習は、カードが、いちばん上に来る。
- ライトとダークの両方に、対応（CSS の変数）。

**追加**
- 登録元（教材と単元）を、先に選べる。教材：でる1000、金フレ、公式問題集12、公式問題集13。単元は、でる1000と金フレだけ（`MATS` を参照）。選んだものは、覚える。
- 一度に40語まで。語は、1行に1語、またはカンマ区切り。熟語も、そのまま入れる。
- **登録済みの語を入れるとエラー**（赤い枠）。ただし、登録元を選んでいて、その語に、その登録元が、まだ付いていないときだけは、登録元を追加する（エラーにしない）。
- 意味が大きく違う多義語は、すぐには登録せず、「意味を選んでください」の欄に、並べて、チェックで選ぶ（複数可）。選択待ちは、保存される。
- 派生語（名詞形・形容詞形など）が、一緒に付く。

**単語帳**
- 1語1枚のカード：単語、発音記号、発音ボタン、品詞、ジャンル、登録元、意味、例文、訳、見出し語、派生語、ボタン（編集・意味を選ぶ・作り直す・削除）。
- 削除は、2回押し（「本当に削除」）。状態は、一覧が描き直されても、残る。
- 「まとめて選ぶ」：選んだ語に、登録元を、まとめて付ける・外す。
- 編集の中で、登録元と、「読み上げ用の綴り」（発音がおかしい語用）を、直せる。
- 「派生語を調べる」の行は、調べていない語があるときだけ、出る。

**復習**
- 範囲（教材と単元）を選ぶ。**範囲の語を、1周するまで、同じ語は、出ない**（ランダム順）。進み具合は「3 / 400」の形。範囲ごとに、覚える。
- 「習得済み」の仕組みは、**廃止した**。覚えているのは、「わからない」を押した回数（`m`）と、その時刻（`mt`）だけ。
- **長押しで答えが出る**：「わかる」「わからない」を、約0.15秒、押し続けると、答えが出る。**同じボタンの上で、離すと、そのボタンを押したことになる。ボタンの外で、離すと、取り消し**（答えは、出たまま）。素早く押せば、答えを見ずに、決められる。
- 長押ししても、**ボタンの位置が動かない**（答えの枠は、固定の高さ）。**文字が選択されない**（`user-select: none`、メニューも出さない）。
- 「わかる」を押すと、その語は、**間違いから、自動で外れる**（`m` を 0 に）。「わからない」を押すと、`m` が増えて、間違いに入る。
- 周の最後に、「もう一周する」と「わからなかった語だけ復習する」。
- 「例文」ボタン：オンの間は、答えを出す前から、例文を、答えの枠に、出す。設定は、覚える。
- 次の語に移ったとき、自動で発音する（最初の1語は、自動では、読まない）。
- 発音：「発音の声」を選べる（おまかせ＝自然な声を優先、速さ優先、声の名前）。読み上げは、取りこぼしを、防ぐ作り（取り消した直後は、少し待つ、1回だけ、やり直す）。

**間違い**
- 「わからない」を押した語の一覧（新しい順）。「確認した」で、一覧から外れる。教材で、絞れる。

## 7. 状況と、残っていること
- **Supabase との同期は、にせのサーバー（`tools/dev_server.py`）では、確認済み。本物の Supabase では、まだ試していない。** 持ち主が、いま、Supabase の準備（プロジェクト作成、SQL の実行、URL とキーの入力）を、している。つながらないときの原因は、「設定」の「接続を試す」が、日本語で、教えてくれる。
- OpenAI の API も、本物では、試していない（にせのサーバーでは、確認済み）。
- 自動テストは、ない。足すなら、Playwright などで、次を、確かめると良い：追加→復習→間違いの流れ、復習の長押し、画面の収まり（1257×603）、スマホ幅（375×812）。
- 同期の限界：変更が、ほかの端末に届くまで、約20秒。同じ語を、2台で、同時に直すと、あとから保存したほうが、残る。`localStorage` の上限は、約5MB。
- リスニングプレーヤー（別のアプリ）の「単語帳へ」ボタンは、古い claude.ai のアドレスを、持っている。直せない（本体の中にある）。選んだ英語の、クリップボードへのコピーは、動く。
