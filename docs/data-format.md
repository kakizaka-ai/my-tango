# 語のデータの形式

1語が、1つの JSON オブジェクトです。保存先（ブラウザの `localStorage`、Supabase）でも、バックアップ（`data/words-backup.json`）でも、同じ形です。

## バックアップのファイル
```json
{ "format": "mytango-backup", "version": 1, "exportedAt": "2026-11-22T…", "count": 149, "words": [ { …1語… }, … ] }
```
「設定」の「取り込み」は、次のどちらも読めます。
- 上の形のファイル（`words` の中の配列）
- 語のオブジェクトだけの配列 `[ {…}, {…} ]`

## 1語の項目
| 項目 | 型 | 内容 |
|---|---|---|
| `word` | 文字列（必須） | 見出しの語・熟語。取り込みでは、これだけでも通ります |
| `pos` | 文字列 | 品詞：`名` `動` `形` `副` `前` `接` `熟語`。空白を含む語は、`熟語` |
| `meaning_ja` | 文字列 | 日本語の意味。複数なら「、」で区切る |
| `ipa` | 文字列 | 米音の発音記号。前後のスラッシュは付けない |
| `genre` | 文字列 | ジャンルの id：`hr` `law` `fin` `sales` `mfg` `office` `travel` `build` `health` `edu` `env` `state` `action` `gen` `other`（意味は `docs/wordbank_spec.md` の第5節） |
| `set` | 文字列 | 常に `user` |
| `example` | 文字列 | 例文。対象の語を `*…*` で1か所だけ囲む（例：`*accept* an offer`） |
| `example_ja` | 文字列 | 例文の訳 |
| `headword` | 文字列 / null | 基本になる語（例：`accepted` の `accept`） |
| `derived` | 配列 | 使いません（常に `[]`）。互換のために残してあります |
| `dv` | 配列 | 派生語：`[{ "w": "acceptance", "pos": "名", "ja": "受け入れ" }]`。**項目がない = まだ調べていない**。`[]` = 派生語なし |
| `sn` | 配列 | 多義語の語義：`[{ "m": "住所", "pos": "名", "ex": "…*address*…", "ja": "…" }]`。2つ以上なら、意味の選び直しができる |
| `sp` | 文字列 | 読み上げ用の綴り（発音がおかしい語だけ。例：`to record`）。空なら、語のまま |
| `src` | 配列 | 登録元（下を参照） |
| `added` | 数 | 追加した時刻（ミリ秒）。一覧の「新しい順」に使う |
| `m` | 数 | 復習で「わからない」を押した回数。0 になると、「間違い」から外れる |
| `mt` | 数 | 最後に間違えた時刻（ミリ秒）。`m` が0なら、ない |
| `s`, `d` | 数 | 昔の「3回連続で習得済み」の仕組みの名残。使いません（0） |

## 登録元（`src`）
`教材` または `教材/単元` の文字列を、並べます。

| 教材 | キー | 単元のキー |
|---|---|---|
| でる1000 | `d1000` | `ch1`（第1章 品詞問題）、`ch2`（動詞問題）、`ch3`（前置詞 or 接続詞問題）、`ch4`（代名詞問題）、`ch5`（前置詞問題）、`ch6`（関係詞問題）、`ch7`（ペア表現・語法・数・比較問題）、`mock`（文法模試） |
| 金フレ | `kinfure` | `l600`（600点レベル 1〜400）、`l730`（730点 401〜700）、`l860`（860点 701〜900）、`l990`（990点 901〜1000）、`s1`〜`s5`（補足編：パート1重要語100、部署・職業名、前置詞・接続詞・接続副詞、多義語88、定型表現120） |
| 公式問題集12 | `k12` | なし |
| 公式問題集13 | `k13` | なし |

例：`["d1000/ch1", "kinfure/l600"]`。教材と単元の一覧は、`src/app.html` の `MATS` にあります。

## 保存のキー（ブラウザの `localStorage`）
| キー | 内容 |
|---|---|
| `mytango-db:words` | 語。`{ "<id>": {…1語…} }`。`<id>` は、語を小文字にして、空白を `_`、英数字と `-` 以外を `~16進~` にしたもの（`src/app.html` の `slug`） |
| `mytango-db-dirty:words` | 同期で、まだ送れていない変更 |
| `mytango-settings` | 設定（API キー、同期の設定） |
| `mytango-rounds` | 復習の周の進み具合（範囲ごと） |
| `mytango-pend` | 多義語の、選択待ち |
| `mytango-src` / `mytango-rev` / `mytango-tab` / `mytango-speak` / `mytango-voice` / `mytango-showex` | 画面の選び方の記憶 |
